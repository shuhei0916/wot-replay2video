プライバシーポリシー（wot-replay2video）

最終更新日: 2026-11-12

1. 概要

wot-replay2video（以下「本アプリ」）は、開発者本人が自分の PC 上で実行し、 自分の YouTube チャンネルに動画をアップロードするための個人用ツールです。 第三者向けのサービスとしては提供していません。

2. 利用する Google ユーザーデータ

本アプリは YouTube Data API を利用し、OAuth 2.0 で認可された範囲で次の操作のみを行います。

  • 動画のアップロード
  • アップロード済み動画のタイトル・説明文・公開設定などの参照と更新

3. データの保存

OAuth のアクセストークン／リフレッシュトークンや動画の情報は、本アプリを実行している PC のローカルにのみ保存されます。開発者のサーバーや第三者に送信・共有することはありません。

4. 第三者への提供

Google ユーザーデータを販売・広告目的で利用したり、第三者へ提供したりすることはありません。

5. 関連ポリシー

  • 本アプリは YouTube API サービスを利用しています。 YouTube 利用規約、 Google プライバシーポリシー が適用されます。
  • 本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に準拠します。

6. アクセス権の取り消し

本アプリへのアクセス権は、 Google アカウントの権限設定ページ からいつでも取り消せます。

7. お問い合わせ

GitHub Issues からご連絡ください。
